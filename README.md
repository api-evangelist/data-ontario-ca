# Ontario Data Catalogue (data-ontario-ca)

Ontario Data Catalogue is a provincial government open-data portal for Canada running **CKAN**, exposing a standardized catalog API over ~2,950 datasets.

**URL:** [Visit APIs.json URL](https://raw.githubusercontent.com/api-evangelist/data-ontario-ca/refs/heads/main/apis.yml)

**Run:** [Capabilities Using Naftiko](https://github.com/naftiko/fleet?utm_source=api-evangelist&utm_medium=readme&utm_campaign=data-ontario-ca-api-evangelist&utm_content=repo)

## Type
- **kind:** government  ·  **software:** CKAN  ·  **version:** 2.9.7

## API
- **Ontario Data Catalogue CKAN Action API** — base `https://data.ontario.ca/api/3/action`. [Docs](https://docs.ckan.org/en/latest/api/) · [Portal](https://data.ontario.ca)
- Live endpoint verified: `https://data.ontario.ca/api/3/action/status_show` · ~2,950 datasets
